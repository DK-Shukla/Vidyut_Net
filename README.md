# ⚙️ Installation

## Clone Repository

```bash
git clone https://github.com/DK-Shukla/Vidyut_Net.git
```

---

## Frontend Setup

```bash
cd frontend
npm install
npm run dev
```

---

## Backend Setup

```bash
cd backend
pip install flask flask-cors ultralytics opencv-python
python backend.py
```
